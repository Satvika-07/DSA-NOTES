# LeetCode 3 — Longest Substring Without Repeating Characters
## Pattern
**Sliding Window + HashMap**
## Problem
Find the length of the **longest substring with no repeating characters**.

## Intuition

* **Brute force:** Generate every substring and check if characters are unique.
* **Optimal:** Maintain a sliding window and move `start` when a duplicate appears.

## Approach
**Brute Force**

1. Choose every starting index.
2. Extend the substring.
3. Use a `HashSet` to check duplicates.
4. Update maximum length.
   
**Optimal**
1. Use `HashMap<Character, Integer>` to store last index.
2. Maintain window `[start...end]`.
3. On duplicate, move `start` to `lastIndex + 1`.
4. Update maximum length.

## Code — Brute Force

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int n = s.length();
        int maxLen = 0;

        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {

                if (hasUniqueCharacters(s, i, j)) {
                    maxLen = Math.max(maxLen, j - i + 1);
                }
            }
        }

        return maxLen;
    }

    private boolean hasUniqueCharacters(String s, int start, int end) {
        HashSet<Character> seen = new HashSet<>();

        for (int k = start; k <= end; k++) {
            if (seen.contains(s.charAt(k)))
                return false;

            seen.add(s.charAt(k));
        }

        return true;
    }
}
```

## Code — Optimal

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        HashMap<Character, Integer> map = new HashMap<>();

        int start = 0;
        int maxLen = 0;

        for (int end = 0; end < s.length(); end++) {
            char ch = s.charAt(end);

            if (map.containsKey(ch)) {
                start = Math.max(start, map.get(ch) + 1);
            }

            map.put(ch, end);

            maxLen = Math.max(maxLen, end - start + 1);
        }

        return maxLen;
    }
}
```

## Dry Run

`s = "abcabcbb"`

* `a` → `"a"` → 1
* `b` → `"ab"` → 2
* `c` → `"abc"` → 3
* next `a` → move `start`
* continue...

**Answer = 3**

## Time Complexity
**Brute Force:** O(n³)
**Optimal:** O(n)

## Space Complexity
**Brute Force:** O(n)
**Optimal:** O(n)

## Key Takeaway

**Brute force checks every substring. Optimal uses Sliding Window + HashMap to jump past duplicates.**
