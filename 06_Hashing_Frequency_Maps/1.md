# LC 1 — Two Sum
## Pattern -- HashMap / Lookup
## Problem -- Find two indices whose values add up to `target`.

## Intuition -- For each number, check if its **complement = target - nums[i]** already exists.
## Approach
1. Create HashMap: `value → index`
2. For each element, find complement.
3. If complement exists → return both indices.
4. Otherwise, store current element.
## Code
```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        HashMap<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int x = target - nums[i];

            if (map.containsKey(x))
                return new int[]{map.get(x), i};

            map.put(nums[i], i);
        }

        return new int[]{};
    }
}
```

## Dry Run

`[2,7,11,15], target = 9`

* `2` → need `7` → not found → store `2`
* `7` → need `2` → found → return `[0,1]`

## Time Complexity  **O(n)**
## Space Complexity **O(n)**

## Key Takeaway
**Store previous elements and check the complement.**
