# LeetCode 733 — Flood Fill

## Pattern

**Grid + DFS**

## Problem

Starting from `(sr, sc)`, change all **connected cells having the same original color** to `newColor`.

## Intuition

Start DFS from the given cell.
Change its color, then visit its **4 neighboring cells**.

## Approach

1. Store the original color.
2. If `original == newColor`, return.
3. DFS from `(sr, sc)`.
4. If cell has original color → change it.
5. Visit **up, down, left, right**.

## Code

```java
class Solution {
    public int[][] floodFill(int[][] image, int sr, int sc, int newColor) {
        int color = image[sr][sc];

        if (color != newColor) {
            dfs(image, sr, sc, color, newColor);
        }

        return image;
    }

    public void dfs(int[][] image, int r, int c,
                    int color, int newColor) {

        if (image[r][c] == color) {
            image[r][c] = newColor;

            if (r >= 1)
                dfs(image, r - 1, c, color, newColor);

            if (c >= 1)
                dfs(image, r, c - 1, color, newColor);

            if (r + 1 < image.length)
                dfs(image, r + 1, c, color, newColor);

            if (c + 1 < image[0].length)
                dfs(image, r, c + 1, color, newColor);
        }
    }
}
```

## Time Complexity

**O(m × n)**

## Space Complexity

**O(m × n)** — recursion stack in worst case.

## Key Takeaway

**DFS + 4 directions + change the color when the cell matches the original color.**

### Alternate Easy Code

This version uses a separate `visited` array, so the logic can be easier to understand:

```java
class Solution {
    public int[][] floodFill(int[][] image, int sr, int sc, int newColor) {
        int oldColor = image[sr][sc];

        if (oldColor == newColor)
            return image;

        boolean[][] visited = new boolean[image.length][image[0].length];

        dfs(image, visited, sr, sc, oldColor, newColor);

        return image;
    }

    void dfs(int[][] image, boolean[][] visited,
             int r, int c, int oldColor, int newColor) {

        if (r < 0 || r >= image.length ||
            c < 0 || c >= image[0].length ||
            visited[r][c] ||
            image[r][c] != oldColor) {
            return;
        }

        visited[r][c] = true;
        image[r][c] = newColor;

        dfs(image, visited, r - 1, c, oldColor, newColor);
        dfs(image, visited, r + 1, c, oldColor, newColor);
        dfs(image, visited, r, c - 1, oldColor, newColor);
        dfs(image, visited, r, c + 1, oldColor, newColor);
    }
}
```

**Interview shortcut:** For grid problems, immediately think **DFS/BFS + 4 directions + boundary check**.
