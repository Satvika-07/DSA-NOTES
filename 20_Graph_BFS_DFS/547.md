# LeetCode 547 — Number of Provinces
## Pattern
**Graph + DFS + Visited Array**
## Problem
Find the number of **connected groups (provinces)** in the graph.

## Intuition
Start DFS from every **unvisited city**.
One DFS visits one complete province, so **count++**.

## Approach

1. Create `visited[]`.
2. For each city, if unvisited → start DFS.
3. DFS visits all connected cities.
4. Increment `count` after each DFS.

## Code

```java
class Solution {
    public int findCircleNum(int[][] isConnected) {
        int count = 0;
        int n = isConnected.length;
        boolean[] vis = new boolean[n];

        for (int i = 0; i < n; i++) {
            if (!vis[i]) {
                dfs(isConnected, vis, i);
                count++;
            }
        }
        return count;
    }

    public void dfs(int[][] isConnected, boolean[] vis, int i) {
        vis[i] = true;

        for (int j = 0; j < isConnected.length; j++) {
            if (!vis[j] && isConnected[i][j] == 1) {
                dfs(isConnected, vis, j);
            }
        }
    }
}
```

## Dry Run

`isConnected = [[1,1,0],[1,1,0],[0,0,1]]`

* Start `0` → DFS visits `0,1` → `count = 1`
* `1` already visited
* Start `2` → DFS visits `2` → `count = 2`

**Answer = 2**

## Time Complexity **O(n²)**

## Space Complexity  **O(n)** — `visited[]` + DFS recursion.

## Key Takeaway

**Every DFS started from an unvisited node represents one province.**
