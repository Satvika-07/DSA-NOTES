# LeetCode 785 — Is Graph Bipartite?
## Pattern **Graph + BFS + Coloring**

## Problem Check whether the graph can be divided into **2 groups** such that connected nodes are in different groups.

## Intuition

Color each node with **1 or 2**.
Every neighbor must get the **opposite color**.

If two connected nodes have the **same color** → not bipartite.

## Approach

1. Create `color[]` initialized to `0` = unvisited.
2. For every unvisited node, start BFS and color it `1`.
3. Color every neighbor with `3 - color[node]`.
4. If neighbor already has the same color → `false`.
5. If all nodes are valid → `true`.

## Code

```java
class Solution {
    public boolean isBipartite(int[][] graph) {
        int n = graph.length;
        int[] color = new int[n];

        for (int i = 0; i < n; i++) {
            if (color[i] != 0) continue;

            Queue<Integer> q = new LinkedList<>();
            q.add(i);
            color[i] = 1;

            while (!q.isEmpty()) {
                int node = q.poll();

                for (int neighbor : graph[node]) {

                    if (color[neighbor] == 0) {
                        color[neighbor] = 3 - color[node];
                        q.add(neighbor);
                    }
                    else if (color[neighbor] == color[node]) {
                        return false;
                    }
                }
            }
        }

        return true;
    }
}
```

## Dry Run

`0 → 1 → 2`

* `0` → color `1`
* `1` → color `2`
* `2` → color `1`
* No connected nodes have the same color → **true**

## Time Complexity **O(V + E)**
## Space Complexity **O(V)**

## Key Takeaway
**Bipartite = 2-coloring.**
For every edge, the two connected nodes must have **different colors**.

**Shortcut:** `3 - color[node]` switches `1 ↔ 2`.
