# LeetCode 994 — Rotting Oranges
## Pattern -- **Grid + DFS + Shortest Time**

## Problem
Find the **minimum time** needed for all fresh oranges to become rotten.
If some fresh orange can never rot → `-1`.

## Intuition
Start DFS from every rotten orange and store the **minimum time** needed to reach each cell.

`time[i][j]` = earliest time that cell becomes rotten.

## Approach

1. Set every cell's time to `∞`.
2. Start DFS from every rotten orange with time `0`.
3. Move in **4 directions**.
4. Update a cell only if the new time is smaller.
5. Find the maximum time among fresh oranges.
6. If any fresh orange has time `∞` → return `-1`.

## Code

```java
private void dfs(int[][] grid, int[][] time,
                 int i, int j, int currentTime) {

    if (i < 0 || i >= grid.length ||
        j < 0 || j >= grid[0].length ||
        grid[i][j] == 0 ||
        currentTime >= time[i][j])
        return;

    time[i][j] = currentTime;

    dfs(grid, time, i - 1, j, currentTime + 1);
    dfs(grid, time, i + 1, j, currentTime + 1);
    dfs(grid, time, i, j - 1, currentTime + 1);
    dfs(grid, time, i, j + 1, currentTime + 1);
}
```

## Dry Run

```text
2 1 1
1 1 0
0 1 1
```

Start rotten orange at `(0,0)`:

* Time `0` → `(0,0)`
* Time `1` → `(0,1)`, `(1,0)`
* Time `2` → `(0,2)`, `(1,1)`
* Time `3` → `(2,1)`
* Time `4` → `(2,2)`

**Answer = 4**

## Time Complexity -- **O((rows × cols)²)** in the worst case because DFS can revisit cells from multiple starting oranges.

## Space Complexity -- **O(rows × cols)** — `time[][]` + recursion stack.

## Key Takeaway
**Multiple rotten oranges → calculate minimum time to reach every cell → maximum of those minimum times.**
**Interview tip:** The standard optimal solution is **Multi-Source BFS**, which is simpler and runs in **O(rows × cols)**.
